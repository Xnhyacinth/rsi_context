# P2 budget — 2026-08-15

Official LongMemEval-V2 (Wu et al., arXiv:2605.12493) is **not** the next GPU
job. It has 451 questions, LME-V2-Small ≈ 100 shared trajectories / 25M tokens,
LME-V2-Medium ≈ 500 trajectories / 115M tokens, and truncates gathered memory
to **200k reader tokens**. That is their reader window, not our 8K `ContextPack`.
A3/LME official scoring is blocked until Repair A landscape and isolation pass.

```bash
uv run python scripts/offline_longmemeval_pack.py \
  --root data/longmemeval-v2-data \

```

Do not report that JSON as an official LME score. Image questions are excluded
by the compiler. Full 451×small haystack is a later transfer cell, not a
difficulty repair.
