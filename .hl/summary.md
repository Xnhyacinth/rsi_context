As of 2026-08-29, `docs/study-contract.md` is the normative project charter.
The project is a benchmark and empirical study of bounded externalized
self-improvement at the context-policy locus, not a strict-RSI or new memory
method claim. Recuris is pinned at
`a0479b27a2d08b7fbf2607acf1841a06b121ee91` as a long-horizon reference;
its publication makes first context/memory-evolution claims unavailable. A2 now
hashes five 1,800-second researcher turns per trajectory, but formal task IDs
remain unfrozen and A2 remains blocked on a real causal multi-hop profile,
host-specific spend caps, and attested physical isolation.

The project now has a tested researcher/policy/frozen-reader loop, pinned asset and
serving identities, fresh-process exact-byte policy evaluation, fixed-policy controls,
manifest calibration, and candidate replay.

The strongest qualification artifact is corrected-protocol run `-04`, a real visible-only
Codex trajectory on pinned local Qwen3.6-27B: H0 `0.25`, round 0 `0.00`, round 1 `0.50`.
The H0-aware selector rejected round 0 and selected round 1; both candidates replayed five
times with zero observed item/prediction/score/token variance. Thus the autonomous policy
regression and improvement exceed the measured noise floor on this four-item visible panel.
The mechanism was a content-derived governing-statement filter plus bounded relation
following, not a numeric compression-ratio search.

This is qualification evidence, not a paper-scale claim: four visible questions, one
researcher, one dataset seed, no sealed isolation. The paper remains a benchmark/protocol
plus empirical study.

A target-tokenized hard-panel qualification then measured the generator's nominal 32,768
semantic words as 53,517--53,720 Qwen tokens. With a true 8,192-token policy cap, head,
head-tail, and lexical scored 0.250, 0.375, and 0.875. No-context scored 0; gold-only,
bounded-oracle, and unbudgeted full context each scored 0.875. This panel correctly failed
the pre-registered A2 gate: compositional retrieval was saturated by lexical selection and
dense comparison had a reader/task floor of 0.75 even with complete evidence. A2 was not
started.

Immediate blockers are a target-token-calibrated generator with genuinely held-out hidden
grammar, an executable matched-search grammar and fully bound A2 plan, and a locked policy-
worker launcher that attests the process handling hidden items. Runtime identity preflight
deliberately fails closed for formal mode; it is not physical isolation. Official task
transfer and LongMemEval-V2 scoring follow only after A2 passes.

The v3 generator now natively produced 32,730--32,750 Qwen tokens and structurally distinct
split grammars. Its second 56-call disposable qualification fixed the compositional profile
(head/head-tail/lexical/oracle = 0.25/0.50/0/1.0) but dense comparison scored 0 even with
gold-only and bounded-oracle context. Overall bounded oracle was 0.50. This is another
pre-A2 no-go: the dense task must be reformulated before causal/replay calibration.

The v3b dense replacement repaired that floor. On a new disposable visible fingerprint,
head/head-tail/lexical scored 0.25/0.50/0.375 overall, no-context scored 0, and gold-only,
bounded-oracle, and full context each scored 1.0 on both profiles. The record contains 56
calls, 572,420 input tokens, 539 output tokens, and schema-v4 item predictions. This proves
only that the visible task is complete-evidence solvable and context-allocation sensitive;
the two strongest fixed policies disagree on 3/8 items. Causal, counterfactual, replay,
larger-stratum, controller-runner, and formal-isolation gates remain open, so A2 has not
started.

The restricted `PolicySpecV1` common grammar now has 32 curated configurations. On the
repaired panel with the pinned Qwen tokenizer, compositional has 32 profile-local behavior
classes and dense has 22. This passes the structural >=20-per-profile gate, but all 32 must
still be reader-scored for saturation, and the controller runner/full A2 bindings do not yet
exist.

The hard-dataset fingerprint algorithm now binds each query, chunk identity/span, text hash,
and per-chunk target-token count in addition to answers and provenance. This intentionally
changes future dataset fingerprints; existing v3/v3b result files remain immutable legacy
qualification artifacts under the earlier fingerprint algorithm.

The complete 32-policy causal/replay screen then made 344 successful local-Qwen calls. Full
context scored 1.0, gold-drop 0, counterfactual following 1.0, and the strongest policy
replayed five times at 0.75 with zero observed variance. But 11 policies saturate
compositional at 1.0 and the top two aggregate policies have zero item disagreement. Dense
tops out at 0.50. A2 remains stopped: keep dense, replace compositional, and rerun the whole
grammar rather than only static baselines.

Gate and sealed primary-profile decoy bodies now use distinct grammars while visible text is
unchanged. Structural tests reject wrapper-only differences. This closes one template
shortcut but does not replace the missing physical hidden evaluator.
