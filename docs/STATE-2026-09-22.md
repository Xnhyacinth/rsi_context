## 一、项目定位与契约（当前有效设定）

**问题**（`docs/benchmark-contract-v2.md`，规范章程）：在固定模型服务、
信息权限与资源约束下，不同自我改进方法能否通过连续任务经历改善 Agent 的
信息获取—记忆维护—行动策略，改善能否保留与迁移，长期净收益
`C_total(N) = C_improve + N·C_deploy` 如何，收益分别来自经验内容、策略
更新还是额外计算。

**项目类型**：benchmark + 分析性研究（非方法贡献）。判定测试：删除自家默
认改进算法、让 Recuris/MGM/固定策略参评时论文价值仍成立。

**核心协议语义**（已实现并有测试钉住）：
- 冻结学习快照 + 独立评价分支（代码/记忆**同权**携带；边界 =
  SOURCE/TIME/SCOPE，非内容形状）；
- fixed 臂 = 策略冻结但记忆可操作（"不更新" ≠ "不记忆"）；
- 延续 vs 迁移分开报告；难度门是开发仪器不是永久规则；
- 成本是两列（C_improve / C_deploy）；stage 级分数不是独立样本，
  CI 聚类在世界级；
- 失败轮/工程失败诚实记录（退出码 3 + `failed_rounds[]`），不是阴性结果。

**Reader 分级**：T1 锚（本地钉版）/ T2 版本化 API（当前 live 使用 siflow
Qwen3.6-27B）/ T3 仅兼容。T2 门含方差地板（已实现并运行）。

## 三、参与者与测量机器

- **冻结快照携带**（`participant/snapshot.py`）：freeze（记忆+代码+技能
  一个字节不可变单元，canonical-bytes 深拷贝三边界——评审发现的浅拷贝污
  染已修并有原地变形测试）；`run_evaluation_branch` 组合既有 session flow
  （分支首载 = 携带；分支写永不回写）；`BranchRecord.store` 暴露给泄漏探
  针（双向测试）。
- **轨迹 runner**（`scripts/trajectory_v3.py`）：参考执行器 + 固定 F₀ +
  改进臂（S₀→S₁→…→Sₙ，每轮反馈从**当前快照**探针再生，策略累积——记忆
  也累积，"replace" bug 已修）；三臂进 延续/新世界/回归 分支。
- **Reader→决策通道**（评分前置，已接通）：hook 捕获 reader 的 survey 回
  复（计划推导，按当前世界候选词元校验）与 rule-change 回复（检查名，按
  当前世界词汇校验）——reader 提取质量现在是**被测方差源**；策略仍是政策
  层（rereverify/preference/profiles）。
- **分级信号**：`gate_failure_counts` 逐格（0/1/refused 三值序数，唯一在
  2×2×2 规模诚实的分级信号；analyze-grading 的反推荐清单在案——不分级
  plan 质量/provenance_retention/加权综合分）。
- **两个方差地板**：
  - T2 reader 地板 `--variance-repeats N`（≥5，新鲜重测 pass-fraction，
    0.05 上限，sd/flip/within_ceiling）；
  - **researcher-in-the-loop 地板** `--author-repeats N`（同一 S₀+反馈的
    N 次独立执笔，每 draw 分支评估，逐 draw 记录含 `usage.attempts`）。
- **improver 可靠性门**：轨迹轮跑 5 次尝试/10 秒退避（矩阵 3 的空回复是
  默认 3 次下的重试抵抗型）；失败轮退出码 3 + `failed_rounds[]`；
  `ResearcherRoundFailure` 携带 attempt log（成功与失败两路径都有——
  本轮修复的失败路径丢日志 bug + 陈旧 usage bug 都在案）。
- **崩溃可区分性**（评审 2.2 端到端 pin）：通过的 S₁ 格必须
  `strategy_errors == []`——损坏的研究者编辑与真实通过不可混淆。
- **分析器**（`scripts/matrix_analyze.py`）：逐快照 pass 率 + gate-failure
  列 + 两个地板的表头 + n/a 语义（未运行单元集绝不为 0/N）。

`trajectory-v3-20260921.md`（harness 版闭环：S₁ 世界泛型策略过两表面）

——迁移面靠的是世界泛型政策而非计划名查找；C_improve = 1357 tokens，比
C_deploy 低两个数量级）。

### 诚实边界（贯穿所有记录）

- 矩阵 = screen-with-repetition（世界内格共享历史；变体面 = 一对父世界；
  无 CI）；世界是 binding N（扫描的功效指导：门二值对比几个世界即够，
  评分分级需 ~O(100–350) 聚类条目）；
- 单 researcher draw 在此端点 ≈ 2:1 硬币——**任何 researcher 臂声明必须
  报告 draw 分布**；
- 至今观测的全部 author-variance = 端点可靠性成分；真正的执笔方差（完成
  的 draw 仍失败）**尚未被观测到**；
- 单次运行无种子的两份早期轨迹是 screen 不是 test（复现矩阵正是为此而
  建）。
