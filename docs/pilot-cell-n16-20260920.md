the visible stream; the stateful hook re-feeds them, which both defeats the
INSUFFICIENT/e-empty failure modes trivially and saturates the panel. The
family's difficulty contract intended state to carry **method experience**
(notes on extraction strategies, provenance habits), not per-item answers.

failed_directions discipline: the instrument, not the science, moved.
