## Matrix design

- **Seeds 11 / 29** vary PRESENTATION ONLY (branch session ids, probe
  surface sampling). World material is never seed-dependent — material
  variance belongs to the world pool, presentation variance to the seed
  axis.
- **Rounds 2**: S₀ → S₁ → S₂. Each round's restricted feedback is
  REGENERATED from the CURRENT snapshot's probe, so round 1 sees round
  0's residual failures; the researcher's strategy file is cumulative.
- **Fixed F₀ control** runs through the same presentation per seed.

## The finding the matrix exists for

**Researcher seed 29, round 0 produced a BROKEN strategy** — and the
matrix caught it with full causal attribution:

- Round 0's `choose_plan` returned `""` intending "decline to
  override"; the empty string was passed through as the literal plan
  name, and the gate refused every commit: `commit gate: plan '' is
  not in the legal set` — S₁ 0/6.
- Round 1's feedback carried exactly that named failure. The
  researcher's round-1 strategy documents its own diagnosis ("an empty
  string is itself an illegal plan on every world") and changes the
  contract: return `None` to mean "no opinion", which the harness
  treats as a true abstention. S₂ 6/6.

This is the first observed instance of **feedback-driven self-repair
across improvement rounds** on the v3 surface: a real failure, a real
cause, a real repair — each round's outcome distinguishable
(crash/no-repair/repair) rather than pooled into a mean. Seed 11 by
contrast repaired in one round; running two seeds made the variance
visible instead of hiding it in a single favorable draw.

Also worth recording: seed 29's round-1 edit is NOT the same file as
seed 11's round-0 edit — the researcher re-derives the world-generic
policy per seed (both converge on "no hardcoding; abstain properly"),
which is what a world-generic policy should do.

## What this matrix does and does not support

- **Supported** (one counting unit throughout: variant-cells = 2
  variants × 3 branch kinds per snapshot): the S₀→S₁ contrast is
  stable across 4 independent trajectories — 0/24 variant-cells pass
  before any improvement; 21/24 after round 0 (the 3 failing cells =
  researcher-s29's broken intermediate); 24/24 after round 1 (the
  repair); the fixed-arm control fails 24/24 (experience alone never
  repairs the weakness); no strategy raised an exception (the `plan ''`
  failure was a legal-but-wrong strategy, not a crash — see the code
  review note C2); per-round C_improve is 975–2054 output tokens.
- **Not supported**: significance claims. 2 seeds × 2 rounds × 3 branch
  kinds × 2 variants is a screen-with-repetition: cells within a
  snapshot share history, the variant surfaces are one parent world
  pair, and the 0/24→21/24→24/24 progression has no CI worth computing
  at this n. The matrix's job was to make variance VISIBLE — done: the
  variance exists (one broken intermediate), it has a cause, and the
  loop repaired it.
- The reader is T2 (siflow) with no in-batch replay-variance floor for
  this matrix; the contrast is gate-deterministic (refusal vs pass),
  which does not depend on reader stochasticity, but score-graded
  variants of this design would need the T2 variance gates.
