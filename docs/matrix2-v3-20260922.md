## What the new layers showed

1. **The graded column works and discriminates.** The fixed/S₀ control
   now reads as *how illegal* (6–10 gate failures), not just fail; the
   researcher-s11 S₁ reads as *partially repaired* (4 residual failures:
   new_world fixed, main-surface residual) — an intermediate state the
   binary column cannot express.
2. **The reader channel is the new variance source — by design.**
   Researcher-s11's residual failure is `plan 'aurora' lacks an
   'online-cutover' verification`: the strategy is correct
   (world-generic, rereverify=True, no hardcoding — read in full from
   the artifact), but the READER's rule-change reply this run did not
   surface `online-cutover`, so the reply-derived check set omitted
   it. Score now depends on the reader's extraction quality — exactly
   what the analyze-grading prerequisite ("reader replies must feed
   decisions") was built to make measurable. The s11/s29 researcher
   runs also SWAPPED roles vs matrix 1 (s11 partial + round-1 empty
   reply; s29 clean in one round): with the reader channel live and the
   researcher re-authoring per run, run-level variance is real,
   visible, and attributed (each cell names its residual cause).
3. **The failed-round semantics work live.** Researcher-s11's round 1
   returned an empty reply (APIResearcherEmptyError): recorded as
   `FAILED ROUNDS: [1]`, S₂ kept S₁'s strategy (the accumulation fix),
   and the artifact still distinguishes "the loop ran and one round
   failed" from a complete matrix.
4. **The T2 variance floor passed everywhere** (5 fresh repeats, sd 0.0,
   flip 0.0, within the 0.05 ceiling on all four runs) — the fresh-request
   replay variance of the gate-binary pass fraction is bounded at zero,
   so the S₁ contrasts above are not replay noise. (What the floor does
   NOT cover: researcher re-authoring — the actual source of the s11/s29
   divergence — dev-session drift, and cross-run endpoint drift; per
   docs/research/design-t2floor-20260921.md §limits.)

## What this matrix does and does not support

- **Supported**: the S₀→S₁ contrast remains stable across all four
  trajectories (0/24 pre-improvement); the graded column exposes
  partial-repair states; failed rounds are recorded, not hidden; the
  replay variance floor is measured, not assumed.
- **Not supported**: significance claims (unchanged: 2×2×2×2
  screen-with-repetition; one parent world pair; shared history within
  snapshots). The researcher-arm cross-seed divergence (clean vs
  partial+failed-round) is ATTRIBUTED variance, not an estimate of it.

## Cost note

The reader channel made live runs materially slower (~2.3 h per run vs
~1 h for matrix 1 — every stage's reply now feeds decisions and the
floor adds 5 branch repeats). C_deploy per run grew accordingly; that
is the honest cost of the score-graded prerequisite.
