## Matched action and reset contract

Session 1 gives the worker one complete, pinned historical source under the
same generic document ID/title in both arms. It must request a
`review-complete` receipt and finalize `source_review`. After a real session
reset, the identical session 2 request asks for a simple MIT license form for
the archival fixture: `license = {text = "MIT"}` (`license-table`) or
`license = "MIT"` (`license-string`). It must request `license-review` and
finalize `license_format_decision` with the passing receipt. The source is
not attached in session 2; bounded carry or metered reread is available.

The first-session source document is the only participant-visible variant:
both arms use the same instance IDs, prompts, later request, action names,
and fixed description axes. The evaluator-only legal set is
`license-table` for PEP 621 and `license-string` for PEP 639. The local
verification receipt confirms procedural review, not packaging validity;
the private finalization gate performs the content check. This preserves
the researcher / editable policy / frozen evaluator boundary.

## Offline evidence and limits

The focused test suite passes for both complete-source arms with a fresh
scripted witness per session, environment-issued passing receipts, final
project state, and an action flip. Replacing only the first-session source
with the opposite pinned file leaves the frozen oracle in place and makes
session 2 fail. With source contents and source identity withheld in both
arms, a **fixed** `license-table` or `license-string` action passes exactly
one arm; unlike R8's PEP 1 semantic map, one constant action cannot solve
both. This is a structural discriminability check, **not** a model-invoked
source-free result. The complete source reveals `PEP: 621` or `PEP: 639`
in its header and `/peps/pep-0621.rst` or `/peps/pep-0639.rst` in its
`source_url`. A second scripted control removes **all rule text** while
preserving those identity fields. It maps only the visible URL to the plan
and still passes both two-session worlds. Thus the fixed-plan source-free
arm is too weak to establish dependency on the decisive passages. A model
may already know the public PEP-to-format mapping; this candidate cannot
currently support a long-context source-dependence or reader-difficulty
claim. Full rendered chat tokens and evidence offsets have not been
measured.

Before admitting this card to a fixed-reader panel, freeze its exact pair
and run both an answer-free model-invoked source-free arm and a
**model-invoked identity-only arm** preserving the PEP header and URL but
removing substantive rules. A target-rule intervention must also preserve
source identity while removing or transplanting every equivalent decisive
passage; a model that still succeeds from identity alone fails this
qualification gate. Then require source citation, a second policy strategy,
exact token geometry, and both-session completion on the chosen readers. Treat
the same public PEP corpus as one source parent and do not count the two
files as independent parents. Preserve the historical-only label in any
released task or report.
